# ChatFun Bot

Telegram bot for group chats: downloads videos from links and runs daily chat games, with a Mini App for players and chat admins. Russian-language texts, five tones from ultra toxic to sickly sweet.

Telegram-бот для групповых чатов: качает видео по ссылкам, проводит ежедневные игры и даёт Mini App с рейтингами и админкой чата. Тексты на русском, пять уровней тона: от ультра-токсичного (с матом) до приторно милого.

## Что умеет

**Видео по ссылкам.** Ссылка на YouTube / Shorts, Instagram Reels, Facebook, TikTok, X, VK, Reddit, Pinterest, Threads - бот отвечает на сообщение статусом с живым прогресс-баром, присылает видео ответом и удаляет статус. На диск ничего не сохраняется: загрузка идёт во временную папку в памяти (tmpfs) и удаляется сразу после отправки. Лимит 49 МБ (ограничение Bot API), бот сам понижает качество 720 -> 480 -> 360.

**Игры и развлечения** (каждую админ чата может выключить):

| Команда | Что делает |
|---|---|
| `/hero` | "X дня": раз в сутки случайный участник. Название настраивается: "Герой дня", "Токсик дня", что угодно (`/title`) |
| `/top` | таблица лидеров; при ничьей за 1-е место - 15-минутное голосование, при равенстве голосов побеждает прежний лидер |
| `/pair`, `/pairs` | парочка дня и самые частые пары |
| `/who вопрос` | бот выбирает случайного участника: "кто проставляется?" |
| `/ball`, `/coin`, `/roll [N]` | шар предсказаний, монетка, случайное число |
| `/duel` | дуэль ответом на сообщение (или открытый вызов), кнопки Принять/Отказаться, 50/50; `/duels` - таблица |
| `/stats [день\|неделя\|все]` | кто сколько пишет (хранятся только счётчики, не текст) |
| `/reg`, `/unreg` | участвовать в розыгрышах или выйти |
| `/app` | открыть Mini App |

Ещё бот огрызается, когда ему отвечают или упоминают его, упоминает людей только в первом объявлении (повторы - без пинга) и имеет антифлуд: лишние команды отбрасываются, служебные ответы удаляются через минуту, в токсичных тонах бот ругается на флудера.

**Для админов чата:** `/title Название`, `/add @user1 @user2 Имя` (добавить участников, которых бот ещё не видел: они склеятся с аккаунтом при первом сообщении), `/tone 1-5`.

**Mini App:** вкладки Игры (розыгрыши, "Кто?"), Статистика (активность, дуэли), Скачать (видео в личку), Админ (тон с примерами, названия игр, переключатели функций, участники). Вход по подписи Telegram initData. Глобальные админы (`ADMIN_IDS`) видят все чаты бота, админы чата - только свои.

## Установка

Нужны Docker и Docker Compose. Для Mini App - ещё публичный HTTPS-адрес (реверс-прокси или туннель).

### 1. Бот в @BotFather

1. `/newbot` - получите токен.
2. `/setprivacy` -> ваш бот -> **Disable**. Без этого в группах бот видит только команды и не заметит ссылки и участников. Если бот уже был в группе, удалите его и добавьте заново (или сделайте админом группы: админы видят все сообщения).
3. Для Mini App (по желанию): `/newapp` -> выберите бота, укажите URL из шага 3, придумайте short name - он пойдёт в `APP_SHORTNAME`.

### 2. Запуск

```bash
git clone https://github.com/igrbtn/chatfun-bot.git
cd chatfun-bot
cp .env.example .env
# впишите в .env как минимум BOT_TOKEN и свой Telegram id в ADMIN_IDS
docker compose up -d --build
docker compose logs -f bot
```

В логе должно появиться `Run polling for bot @...`. Добавьте бота в группу и напишите `/help`.

Данные лежат в `./data/chatfun.db` (SQLite). Бэкап - просто копия файла при остановленном боте или `sqlite3 data/chatfun.db ".backup data/backup.db"`.

### 3. Mini App (по желанию)

Контейнер слушает `127.0.0.1:8095` (меняется через `HOST_BIND` / `HOST_PORT`). Опубликуйте его по HTTPS любым способом, например:

- **Cloudflare Tunnel:** маршрут `https://fun.example.com` -> `http://localhost:8095`.
- **nginx / Caddy:** reverse proxy на `127.0.0.1:8095`, сертификат Let's Encrypt.

Затем в `.env`: `WEBAPP_URL=https://fun.example.com` (и `APP_SHORTNAME`, если делали `/newapp`), и `docker compose up -d`. Бот сам поставит кнопку меню в личке.

### 4. YouTube и Instagram (если не качает)

С серверных IP YouTube часто отвечает "Sign in to confirm you're not a bot", Instagram и Facebook тоже могут требовать вход. Решение - cookies вашего аккаунта (лучше отдельного, не основного):

1. Поставьте расширение **Get cookies.txt LOCALLY** (Chrome) или **cookies.txt** (Firefox).
2. В окне инкогнито войдите на youtube.com, экспортируйте cookies в формате Netscape и сразу закройте окно (не выходя из аккаунта).
3. Положите файл в `data/cookies.txt`, в `.env` укажите `COOKIES_FILE=cookies.txt`, перезапустите.

Файл cookies - это живая сессия аккаунта: не коммитьте его и никому не отправляйте.

## Настройки (.env)

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `ADMIN_IDS` | глобальные админы, Telegram id через запятую |
| `ALLOWED_CHATS` | работать только в этих группах (id через запятую), пусто = везде |
| `TZ` | часовой пояс для игр "дня", например `Europe/Moscow` |
| `WEBAPP_URL`, `APP_SHORTNAME` | Mini App: публичный https-адрес и short name из /newapp |
| `HOST_BIND`, `HOST_PORT` | где Docker публикует порт Mini App |
| `MAX_UPLOAD_MB`, `MAX_DURATION_SEC` | лимиты видео (по умолчанию 49 МБ и 15 минут) |
| `COOKIES_FILE` | имя cookies.txt внутри `data/` |
| `LOG_LEVEL` | `INFO` или `DEBUG` (входящие сообщения: только id чата и тип) |

## Тексты и тоны

Все реплики - в `texts.yaml` (обычный тон 3) и `tones.yaml` (переопределения для тонов 1, 2, 4, 5). Списки - это варианты, бот выбирает случайный. Тон 1 содержит мат: включайте его только в чатах, где это уместно (`/tone 1`). Тест `tests/test_tones.py` проверяет, что во всех тонах используются только известные подстановки (`{mention}`, `{title}` и т.д.).

## Разработка

```bash
python3 -m venv venv && venv/bin/pip install -r requirements-dev.txt
venv/bin/pytest -q && venv/bin/ruff check .
venv/bin/python scripts/dev_server.py           # Mini App без Telegram: фейковый бот и демо-данные, http://127.0.0.1:8095
venv/bin/python scripts/dev_server.py --global  # то же глазами глобального админа
```

Стек: Python 3.12, aiogram 3, yt-dlp (+ ffmpeg и deno в образе), aiohttp, SQLite. Код `.py`/`.js` - только ASCII, все русские строки в yaml/json.
